# UX messages (owner: UX lead)

1. **Say what happened, then what to do next**, in polite plain Thai. No technical terms, and never start a message with an error code.
2. **Rejection messages must tell the user who holds the slot so they can negotiate** (for example the name or contact of the person who booked it).
3. Show the room and the time in the user's terms, for example "R101 วันจันทร์ 12 ต.ค. 10:00–11:00".
4. One sentence where possible. Never blame the user.

Policy owner: UX lead. Changes to this skill need UX lead sign-off.
